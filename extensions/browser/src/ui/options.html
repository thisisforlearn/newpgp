NewPGP options

How outgoing mail is sent

Send both keeps your words readable to everyone and adds an encrypted copy. PGP only sends just the encrypted block — people without PGP cannot read it.

Turn NewPGP on or off

About draft autosave

Gmail and Outlook can autosave what you type before NewPGP encrypts it. That saved copy lives with your webmail provider. NewPGP itself never writes message text to browser storage, but we cannot control the webmail site.

For highly sensitive mail, use the built-in NewPGP client instead of a webmail compose window.

The NewPGP helper

Encryption happens in the NewPGP desktop app or CLI daemon, which installs a native messaging host named com.newpgp.bridge. Private keys stay there; the browser extension only sends text to be encrypted or decrypted.

If the popup says “Helper not found”, install the NewPGP desktop app, make sure it is running, and reload this extension.

How it works
  1. The content script reads your compose draft in memory only.
  2. The background worker asks the helper to encrypt it for your recipients.
  3. Your original text is kept and the armored block is appended (or replaces it in PGP-only mode).
  4. Incoming blocks get a decrypt button and a signature status.

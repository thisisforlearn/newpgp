What NewPGP does — and doesn't do

          
    
            
  • Uses the OpenPGP standard (RFC 9580), so it works with existing PGP keys and messages.
    • 
            
  • Finds keys automatically via WKD and verified directories; you can also use invite links.
    • 
            
  • Keeps drafts encrypted to yourself, so webmail providers can't autosave your words.
    • 
            
  • Encrypts files of any type: photos, videos, documents.
    • 
            
  • Searches your decrypted mail locally — nothing is sent to a server.
    • 
          

          
Honest limitations

          
    
            
  • Email metadata (sender, recipient, subject, time) is still visible to mail servers.
    • 
            
  • Classic OpenPGP has no forward secrecy. A ratchet-based mode is planned for a later release.
    • 
            
  • Version 0.1 is not independently security-audited. Don't rely on it for life-or-death secrecy yet.
    • 
          

          
NewPGP is not a new cryptographic protocol. It uses rPGP, a pure-Rust OpenPGP implementation.

## How to contribute

Contributions are accepted through any of these channels:

- **GitHub pull requests and issues:** <https://github.com/thisisforlearn/newpgp>
- **Email** code, patches, ideas or bug reports to **nekomeowpurr@proton.me**.
- **Any platform listed from the official project link:**
  <https://github.com/thisisforlearn/newpgp> — send the change through that same
  platform and it will be reviewed.

**More platforms are coming soon.** Setting each one up takes time; the official
links for every platform are listed on the project page above.

Practical steps — formatting, tests, and the licensing note — are in
[CONTRIBUTING.md](CONTRIBUTING.md). Please never include private keys,
passwords, setup codes or real message contents in a public issue or pull
request.
